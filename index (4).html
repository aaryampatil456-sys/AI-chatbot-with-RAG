How the RAG pipeline works

PDF uploadUser adds a PDF in the sidebar.
Text extractionPyPDFLoader reads every page.
ChunkingRecursiveCharacterTextSplitter makes small pieces.
EmbeddingsMiniLM-L6-v2 turns text into vectors.
FAISS searchFinds chunks closest to the question.
Gemini answerWrites a natural reply from those chunks only.

What you get

Grounded answers

If the PDF doesn't say it, the bot says it isn't available. No made-up facts.

Page sources

Every answer has an expandable list of retrieved passages with page numbers.

ChatGPT-style chat

Clean conversation view with a Clear Chat button and document status in the sidebar.

Safe API key

The Gemini key lives in a .env file and never appears in the code or the interface.
